## 🚀 Live Demo

Open `index.html` directly in your browser — no server needed!

---

## 🎯 Features

| Module | Description |
|--------|-------------|
| 📊 **Dashboard** | Live stats, revenue charts, real-time check-in feed |
| 👥 **Members** | Add/search/filter/delete members with full profiles |
| 📅 **Scheduling** | 7-day weekly class grid, slot booking system |
| 💳 **Billing** | Invoice generation, payment tracking, retry failed payments |
| 🏋️ **Trainers** | Trainer cards with ratings, experience, salary details |
| 📈 **Analytics** | Check-in trends, class popularity, retention rate, revenue breakdown |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Dark glassmorphism UI, animations, responsive design
- **JavaScript (Vanilla)** — Full interactivity & data management
- **Chart.js** — Interactive analytics charts
- **Google Fonts** — Outfit typeface
